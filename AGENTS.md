# Agent Rules

These rules apply to all agent work in this repository.

1. Never push code or other changes to GitHub or any remote repository.
2. Do not edit, create, delete, move, or format project files unless the user explicitly asks for that change.
3. When the user asks how to make a change, inspect the code and explain or show the proposed changes by default. Let the user apply them unless they explicitly ask the agent to edit the files.
4. Preserve all existing staged, unstaged, and untracked user changes. Do not overwrite, revert, reset, or discard them.
5. Read-only inspection and analysis are allowed when answering questions about the project.
